# 🏗️ Smart Construction Estimation System

### C++ Based Construction Cost & Material Estimation

A smart construction estimation system developed as a B.Tech Civil Engineering mini project. The system helps estimate construction materials and approximate project cost based on building dimensions, structural details, labour requirements and applicable PWD/SOR rates.

## 📌 Project Overview

The Smart Construction Estimation System is designed to provide a simple and practical method for preliminary construction cost estimation.

Users can enter building dimensions and construction details, after which the system calculates an estimated project cost and provides a cost summary.

## ✨ Features

- Building area calculation
- Foundation cost estimation
- RCC work estimation
- Brickwork estimation
- Plaster cost estimation
- Flooring cost estimation
- Painting cost estimation
- Steel quantity and cost calculation
- Labour cost estimation
- Water charges
- Carpenter charges
- Security charges
- PWD / SOR based estimation approach
- Detailed cost summary
- Print / Save as PDF option
- Responsive web interface

## 🧱 Construction Details

The system accepts parameters such as:

- Length and breadth of building
- Number of floors
- Floor height
- External and internal wall thickness
- Door and window opening area
- Mortar ratio
- Slab thickness
- RCC columns and beams
- Foundation type
- Strip footing dimensions
- Isolated footing dimensions
- Structural steel quantity
- Labour and manpower details

## 💻 Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## 🎯 Objective

The main objective of this project is to develop a simple construction estimation tool that can help students, engineers and users prepare a preliminary estimate of construction cost.

## ⚠️ Disclaimer

This system provides an approximate construction estimate based on the entered parameters and applicable PWD/SOR rates.

Material quantities are approximate and actual requirements may vary depending on design, site conditions and construction practices.

Steel quantity should always be verified through proper structural design by a qualified structural engineer.
